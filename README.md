# Cavli build environments

Docker build environments for Cavli firmware. Pick the README of your product:

- [cqm2xx/README.md](cqm2xx/README.md): cqm220, cqm212 and cqm211 (`cqm2xx/cqm2xx-setup`).
- [aq62/README.md](aq62/README.md): AQ62 (SA525M) apps build (`aq62/aq62-setup`).

Other directories: `cqm22x/` is the previous tool (`cqm22x-setup`, all lines, unchanged); `sdx/`, `sdx35/`, `c10qm/`,
`cqs290/`, `le/` and `common/` are legacy environments, unchanged.
