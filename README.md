# Cavli build containers

Docker build environments for Cavli CQM2xx firmware.

- **[cqm2xx/](cqm2xx/README.md)** — the current tool, `cqm2xx-setup`. Start with
  [cqm2xx/README.md](cqm2xx/README.md). Covers cqm220 (cqm220-0 and cqm220-3) for now.
- `cqm22x/` — the previous tool, `cqm22x-setup`. Unchanged and still works (all
  lines, including cqm211 and cqm212).
- `sdx/`, `sdx35/`, `c10qm/`, `cqs290/`, `le/`, `common/` — legacy environments
  for older products, kept unchanged.
